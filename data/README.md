# Data dictionary

` supplier_payments.csv ` is a synthetic portfolio dataset created for reproducible SQL and Power BI analysis.

## Columns

- `payment_id` — unique transaction identifier
- `supplier_id` — numeric supplier identifier
- `supplier_name` — supplier display name
- `payment_date` — transaction date
- `amount` — payment value in USD
- `status` — `paid`, `pending`, or `cancelled`

The sample contains 64 transactions across 8 suppliers from January through August 2026. No real supplier or company data is included.
